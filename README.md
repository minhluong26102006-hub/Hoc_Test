# Shop Bún - Giao Diện Bún Đậu Mắm Tôm

Website giới thiệu và đặt món cho cửa hàng bún đậu mắm tôm "Shop Bún".

## Tính năng nổi bật
- **Tông màu ẩm thực:** Vàng kem, cam nhạt và nâu đậm ấm cúng, ngon miệng, chuẩn phong cách ẩm thực.
- **Phong cách thiết kế:** Góc vuông vức / bo tối đa 2px, đường nét phẳng tinh tế, sạch sẽ.
- **Bố cục đầy đủ:**
  - Header với thương hiệu, thanh menu và huy hiệu số lượng giỏ hàng.
  - Hero Banner giới thiệu các đặc sản nổi bật.
  - Khối sản phẩm đặc biệt (Mẹt bún đậu đặc biệt) với ảnh lớn, chọn combo size và nút mua.
  - Lưới danh sách sản phẩm (CSS Grid: 4 cột desktop, 2 cột tablet, 1 cột mobile).
  - Footer thông tin cửa hàng, giờ mở cửa, địa chỉ và hotline.
- **Tương tác:** Thêm món vào giỏ hàng, thông báo Toast mượt mà và animation nảy badge.
- **Công nghệ:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript thuần.
